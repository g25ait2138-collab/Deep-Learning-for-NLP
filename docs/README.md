# Screenshot provenance

These three PNG charts were extracted from the saved Matplotlib outputs in `notebooks/flowers_classification.ipynb` (reproducible classroom version, seed 42). The first notebook image contained two side-by-side figures; these were cropped into `dataset_plot.png` and `training_loss.png` for clearer README display. `decision_boundary.png` comes from the separate saved decision-boundary figure.

The training dataset has only eight synthetic labeled points; these images are illustrative and do not represent held-out model performance.
